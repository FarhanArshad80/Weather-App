# Weather App Real time updates

A responsive, lightweight web application designed to deliver real-time weather information using HTML, CSS, and JavaScript.

## Features
- **Live weather data**: current conditions, the next few hours and a 5-day forecast.
- **Air quality**: the air index plus PM2.5 and PM10 readings.
- **Share a city**: copy a link to the city on screen, or copy the weather itself as plain text to paste into a chat.
- **Keyboard shortcuts**: press `?` to see them all.
- **Clean UI**: the background changes to match the weather.
- **Responsive design**: works in desktop and mobile browsers.

## Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
